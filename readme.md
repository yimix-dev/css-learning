# CSS from Scratch – Solid Fundamentals

This repository documents my process of learning CSS from scratch,
with a strong focus on understanding how CSS actually works in the browser:
the cascade, inheritance, specificity, and layout fundamentals —
without shortcuts, frameworks, or premature abstractions.

## Objective

- Understand CSS from its real foundations
- Avoid common beginner mistakes and bad practices
- Build a solid base before moving to advanced layouts and frameworks

## Repository Approach

This repository grows progressively.

Each folder is created **only after** a topic has been fully studied
and applied in practice.  
No folders are created in advance.

When a folder exists, it means:

- The concept was studied
- The theory was understood
- The concept was applied using real HTML and CSS

## Structure

Each topic folder contains:

- A README with clear explanations
- A small practical lab using HTML and CSS

# Internal CSS

## CSS rule (selector, property, value)

A CSS rule provides a declarative instruction to the browser to apply visual styles to an HTML element. Each rule consists of: a selector + a block of declarations. All declarations are enclosed in “{}”, which consists of a property and a value. Each declaration ends with a “;”, and a “:” is used to separate the property from the value. If no rules are declared, the browser applies default rules; this is known as the “User Agent Stylesheet.”
